Nina Creator Studio · Windows Desktop

Kreative Videos. Ein Studio.

Desktop-Werkzeug zur Bearbeitung von Gameplay, Erstellung von Clips und Vorbereitung von Social-Media-Beiträgen.

Live Studio

Eigene Live-Szenen für Querformat und Hochformat mit Gameplay, Facecam und Einblendungen.

Clip Studio

Gameplay-Ausschnitte auswählen, Facecam anordnen und Clips zur weiteren Bearbeitung vorbereiten.

Creator Hub

Videoprojekte organisieren, Titel und Beschreibungen vorbereiten und Veröffentlichungen planen.

Wie funktioniert es?

Eine Gameplay-Aufnahme wird lokal importiert oder aufgezeichnet. Danach werden passende Szenen ausgewählt, im Clip Studio bearbeitet und als Videodatei exportiert. Die Social-Media-Verknüpfung ist eine optionale Funktion und wird nur mit der entsprechenden Nutzerfreigabe verwendet.

Zum vollständigen Ablauf

Status der Anwendung: Das Creator Studio wird derzeit weiterentwickelt. Funktionen und verfügbare Integrationen können sich ändern. Eine öffentliche TikTok-Direktveröffentlichung wird nicht als bereits freigeschaltet dargestellt.
